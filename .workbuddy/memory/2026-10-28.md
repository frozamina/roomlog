# 2026-10-28

## 租房记录 App「居志 RoomLog」— 需求分析与设计稿

**背景**：用户要做安卓 APK，用于记录租房客观条件（隔音/采光/面积/户型/家电/水压/电梯等）+ 每月水电账单，目标是沉淀历史数据、识别自己真正在意的居住条件。

**已交付**
- `docs/PRD-RoomLog-v0.1.md` — 完整 PRD：三层价值（记录/复盘/决策）、A–F 六组约 55 项条件字段字典、月度账单字段与派生指标（每㎡成本、水电占比、商电识别）、洞察引擎算法（居所指数 = 体验分 × 在意度加权；偏好权重从退租复盘的"后悔指数"反推 + 显性在意度；红线条件 = 在意度 Top3 × 历史均分 < 3.0）、信息架构、4 个 Tab、里程碑。
- `prototype/ui-prototype.html` — 6 屏 UI 原型（设计稿画廊形式，375×812）。

**设计 DNA**：暖纸底 #FBF9F3 + 墨绿 #2C4A3B + 陶土 #BF6A45 + 芥黄 #C9963C；标题 Noto Serif SC，正文 Inter/Noto Sans SC，数字 tabular-nums；卡片 20–22px 圆角、两层以内阴影。

**技术约束（重要）**：本机无 Java / Flutter / Gradle / Android SDK，只有 Node 22 + Python 3.13。APK 产出有三条路：A 本地装便携 JDK+Android cmdline-tools+Flutter（2–3GB）；B GitHub Actions 云构建；C 先做 PWA 验证习惯再打包。已在 PRD 中给出，待用户拍板。

**验证方法（可复用）**：无 playwright，用 Edge headless 截图校验设计稿：
`"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu --hide-scrollbars --screenshot=out.png --window-size=1400,2600 file:///...`
需要测量元素尺寸时，复制一份 HTML 在尾部追加 script 写入 `document.title`，再用 `--dump-dom | grep` 取回。比肉眼调参可靠。PIL 已安装用于裁剪放大。

**待用户确认**：App 名、首版范围（是否砍洞察）、APK 路径、字段取舍、视觉倾向。
